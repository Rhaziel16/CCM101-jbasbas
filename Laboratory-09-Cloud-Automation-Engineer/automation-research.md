# Automation Research

## 1. Bash Script

A Bash script is a file that contains commands that Linux can execute in order. The `#!/bin/bash` line tells the system to use Bash to run the script.

## 2. Variables

Variables store information such as folder names, file paths, or values that a script needs to use. They make a script easier to read and update because the same information can be reused without typing it repeatedly.

## 3. Cron Job

A Cron job is a scheduled task that runs automatically at a specified time in Linux. It is useful for repeated tasks such as backups because it reduces the need to run commands manually.
