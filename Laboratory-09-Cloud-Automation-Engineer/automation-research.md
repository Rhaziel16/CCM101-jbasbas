# Automation Research

## 1. Bash Script

A Bash script is a file that contains commands that Linux can run in order. The `#!/bin/bash` line tells the system to use Bash to run the script.

## 2. Variables

Variables store information, such as folder names or file paths, that a script can use. They make the script easier to read and update because we do not need to type the same value repeatedly.

## 3. Cron Job

A cron job is a Linux task that runs automatically at a scheduled time. It is useful in cloud operations because it can handle repeated tasks, such as backups, without someone running them manually.
