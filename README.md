# Laboratory 01 — Welcome to the Cloud

## Mission Overview

In this activity, I was introduced to a Linux cloud environment using KillerCoda. I also created a user, checked the system information, organized folders, and prepared my GitHub repository.

## Objectives

* Learn how to use a Linux environment.
* Learn basic Linux commands.
* Check basic system information.
* Create and organize folders and files.
* Create a GitHub repository.
* Use Markdown to document my work.

## Activities Performed

First, I opened the Linux Playground in KillerCoda. I created a new user and logged in using the new account.

After that, I checked the username, working directory, and hostname. I also checked the Linux version, kernel, CPU, memory, and disk space.

Next, I created the required folders and the `about-me.md` file. Finally, I created my GitHub repository and added the required files for Laboratory 01.

## Linux Commands Used

* `whoami` – checks the current username.
* `pwd` – shows the current folder.
* `hostname` – shows the computer name.
* `mkdir` – creates folders.
* `cd` – moves to another folder.
* `ls` – shows files and folders.
* `cat` – displays the content of a file.
* `nano` – creates or edits a file.
* `uname -r` – shows the kernel version.
* `free -h` – shows memory information.
* `df -h` – shows disk space.
* `lscpu` – shows CPU information.
* `git add` – adds files for commit.
* `git commit` – saves changes to Git.
* `git push` – uploads changes to GitHub.

## Skills Learned

I learned how to use basic Linux commands and work with files and folders. I also learned how to check system information and create a user in Linux.

I also learned how to organize my laboratory files in GitHub and use Markdown for documentation.
