# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed an S3-compatible object storage server using MinIO and Docker. I used a KillerCoda Ubuntu Playground to run the MinIO server, access its web console, create a storage bucket, and upload a sample file.

## Objectives

* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server using MinIO and Docker.
* Access a cloud service through a web interface using port forwarding.
* Create a storage bucket and upload an object.
* Document cloud storage operations using Markdown.
* Expand a professional GitHub Cloud Computing Portfolio.

## Tools Used

* GitHub
* KillerCoda
* Docker
* MinIO
* Ubuntu
* Web Browser
* Markdown

## Skills Learned

* Understanding different types of cloud storage.
* Running a cloud storage service using Docker.
* Using environment variables in Docker.
* Accessing services through specific ports.
* Creating and managing an object storage bucket.
* Uploading objects to cloud storage.
* Documenting cloud computing activities using Markdown.
* Managing laboratory work using GitHub.
