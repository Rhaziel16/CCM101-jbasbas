
# Mission 10 Reflection: The Enterprise Cloud Architect

In this laboratory activity, I learned how to build and manage a website using Ghost, MySQL, Docker, and Ubuntu Server. I also learned how VirtualBox and Docker Compose work together to run the system. This activity helped me understand how different tools are used to create a working cloud environment.

I also learned the importance of security when managing a server. By configuring the firewall and limiting the ports that can be accessed, I understood how to protect the system from unwanted connections. Keeping passwords secure and avoiding exposing the database also helped me understand the value of proper security settings.

Another lesson I learned was how to automate backups and restore data when needed. The Bash script and cron job made it possible to create database backups automatically every day. Testing the restore process showed me why backups must be checked to make sure they contain the correct data.

Overall, this activity improved my knowledge of cloud computing, server management, and system maintenance. I realized that creating a system is not only about making it work but also about keeping it secure, preparing for possible problems, and documenting the proper procedures. This experience helped me become more patient and prepared when handling technical tasks.
