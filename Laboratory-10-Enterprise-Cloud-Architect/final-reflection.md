
# Mission 10 Reflection: The Enterprise Cloud Architect

In this activity, I learned how to run a website and a database using Docker. I used Ghost for the website and MySQL for storing data. I also learned how Docker containers work together to make an application run properly. This activity helped me understand how different services can be managed in one environment.

I also learned how Docker volumes keep data even when containers are stopped or restarted. Another important part of the activity was using the UFW firewall to control incoming connections. I learned that a firewall helps protect a system by allowing only the necessary connections and preventing unwanted access.

In addition, I used a Bash script and cron to automate database backups. This helped me understand how automation can save time and reduce manual work. Testing the backup and restore process also taught me why it is important to keep copies of important data and make sure they can be restored when needed.

One challenge in this activity was making sure all parts of the system worked together properly. I needed to check the containers, firewall settings, and backup files to ensure everything was working as expected. This experience taught me to be patient when troubleshooting and to check each part carefully whenever a problem occurs.

Overall, this activity helped me improve my knowledge of Docker, database management, firewall configuration, and backup automation. If I improve this project in the future, I would store backup copies outside the virtual machine, add HTTPS for better security, and use system monitoring to check the condition of the application. I learned that managing a cloud system is not only about making it work but also about keeping it secure, protecting its data, and making sure it can recover from unexpected problems.
