
# Mission 10 Reflection: The Enterprise Cloud Architect

In this activity, I learned how to run a website and a database using Docker. I used Ghost for the website and MySQL for storing data. I also learned how Docker volumes keep data even when containers are stopped or restarted.

I learned how to use the UFW firewall to control incoming connections. I also used a Bash script and cron to make database backups automatically. Testing the backup and restore helped me understand why backups need to be checked and why they are important when data is lost.

One challenge in this activity was making sure all parts of the system worked together. I needed to check the containers, firewall, and backup files. This activity helped me practice what I learned in our previous cloud computing lessons.

If I improve this project, I would save backup copies outside the virtual machine and add HTTPS and system monitoring. Overall, this activity taught me that setting up a cloud system is not only about making it work. It is also important to keep it secure and protect its data.
