# Client Recommendations

## Checkpoint 4 – Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

I would recommend AWS for this startup because its main problem is balancing a limited budget with expected growth. The company does not need a very large environment immediately, so it can begin with the resources needed for the first version of the mobile application. As the number of users increases, additional AWS resources can be added. This makes AWS a practical option for a startup that expects its workload to change over time.

### Suggested Services

- Amazon EC2 – for application servers
- Amazon S3 – for storing files and application objects
- Amazon RDS – for the application's relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

I would recommend Microsoft Azure because the university already depends on Microsoft products. Using Azure would make sense because its services can work with Windows Server and Microsoft identity technologies. The university can also move selected systems instead of transferring everything at once. This makes Azure suitable for a gradual migration.

### Suggested Services

- Azure Virtual Machines – for existing Windows or Linux workloads
- Microsoft Entra ID – for identity and access management
- Azure SQL Database – for relational database workloads

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

I would recommend Google Cloud because the company's main workload involves Artificial Intelligence and Machine Learning. The platform has services designed for AI development and can also provide virtual machines for computing workloads. If the company uses containers, Google Kubernetes Engine can help manage those applications. These features fit the company's technical requirements better than simply choosing a provider based on general popularity.

### Suggested Services

- Vertex AI – for AI and machine learning workloads
- Compute Engine – for virtual machine workloads
- Google Kubernetes Engine – for containerized applications

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

I would recommend AWS for this company because an international online store needs its application to remain available while traffic changes. The company can use load balancing to distribute incoming requests and automatic scaling to add or remove computing resources. It can also use database and content delivery services to support its customers. These features are useful for an e-commerce system that may experience sudden increases in traffic.

### Suggested Services

- Amazon EC2 – for application servers
- Elastic Load Balancing – for distributing incoming traffic
- EC2 Auto Scaling – for adjusting the number of running instances

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | It provides many services and can scale as the startup gains more users. |
| Enterprise Organization | AWS | Its large selection of services can support different enterprise workloads. |
| Microsoft Environment | Azure | It is a good match for organizations already using Microsoft technologies. |
| AI / Machine Learning | GCP | It provides strong services for AI and Machine Learning workloads. |
| Kubernetes Deployment | GCP | Google Kubernetes Engine provides a managed Kubernetes environment. |
| Global Web Application | AWS | Its global infrastructure and scaling services can support applications with changing traffic. |
