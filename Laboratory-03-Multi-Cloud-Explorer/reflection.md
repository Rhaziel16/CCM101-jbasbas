# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most was Google Cloud. I found its Artificial Intelligence, Machine Learning, and Kubernetes services interesting because they are useful for modern applications. Before this activity, I mostly saw cloud computing as using online servers and storage, but this activity showed me that cloud platforms offer much more than that.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP provide many of the same basic cloud services. All three have virtual machines, storage, networking, databases, identity management, and other tools for building applications. The main difference is that each provider has its own service names, features, and areas where it is particularly strong.

## 3. How do business requirements influence cloud platform selection?

Business requirements help determine which cloud provider makes the most sense for a company. Budget, existing technology, application type, number of users, security needs, and future growth can all affect the decision. For example, Azure is a logical choice for a company that already uses Microsoft products, while Google Cloud can be useful for an organization focused on AI and Machine Learning.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that selecting a cloud provider should start with the client's actual problem. A provider should not be selected just because it is popular. I also learned how to compare equivalent services and use the client's requirements to explain why one platform may be more suitable than another.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub portfolio became more organized after completing this activity. I added separate research files for AWS, Azure, and Google Cloud, comparison tables, client recommendations, a decision matrix, Linux investigation results, and screenshots. The repository now shows not only the information I researched but also the decisions I made from the different client situations.
