## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

I would select AWS for this category because its service catalog covers many different areas of cloud computing. It can provide resources for basic applications as well as more complicated business systems.

### 2. Which provider best integrates with Microsoft technologies?

Azure is the better match for Microsoft technologies. A company already using Windows Server, Microsoft 365, and Microsoft identity tools can connect its existing environment with Azure more naturally.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for both AI and Kubernetes. Its AI services can support machine learning projects, while Google Kubernetes Engine can be used to manage containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would choose AWS for general cloud projects because I would have many services to choose from. I also think it would be useful when a project starts small and later needs more cloud resources.
