# Cloud Provider Comparison

## Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

## 1. Which cloud provider offers the broadest range of services? Explain your answer.

For me, AWS offers the broadest range of services. It has many choices for computing, storage, networking, databases, security, and other cloud needs.

## 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would choose Microsoft Azure for an organization that already uses many Microsoft products. Azure is made to work well with Microsoft's services, which can make it easier to manage the organization's cloud resources.

## 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely known for its AI and machine learning services. It also provides Google Kubernetes Engine, which is used for running and managing Kubernetes applications.

## 4. What similarities did you observe among the three cloud providers?

All three providers offer the same basic types of cloud services. They all have computing, storage, networking, and identity services, but the names and features are different.

## Summary

AWS, Azure, and Google Cloud all provide the main resources needed for cloud infrastructure. The main difference is how each provider names and delivers its services.
