# Mission Reflection

This activity gave me a better idea of what is behind the cloud services that we use. I was able to check a real Linux environment in KillerCoda and see its CPU, memory, storage, and network information. It was more helpful than just reading about these components because I was able to check them myself.

For me, compute is one of the most important parts of cloud infrastructure because it is responsible for processing tasks and running applications. If there is not enough computing power, an application may not work properly or may become slow. The other components are still important because they support the work done by the server.

Linux supports cloud computing by giving the server an operating system that can manage its resources. Through the terminal, I was able to check different parts of the server and run commands to get information about it. This made me more familiar with using Linux commands.

Technical documentation is also important because it keeps information about the infrastructure organized. Before setting up a system, it is useful to know what resources are available and how they will be connected. It can also help when checking or fixing the system later.

One of the new skills I learned was checking server information using Linux commands. I also learned how to compare the services of AWS, Azure, and Google Cloud even though they use different names for similar services. Making the cloud infrastructure diagram also helped me understand how the components are connected.

My GitHub portfolio improved because I added another complete laboratory activity with reports, comparison, screenshots, and a diagram. It is becoming more organized and shows the different things I have learned about cloud computing.
