# Mission 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity is about learning the basic parts of cloud infrastructure. I used KillerCoda to check a Linux server and looked at its CPU, memory, storage, network, and operating system. I also compared AWS, Microsoft Azure, and Google Cloud Platform.

## Objectives

- Investigate a Linux server using KillerCoda.
- Identify the main parts of cloud infrastructure.
- Understand compute, storage, networking, and operating systems.
- Compare AWS, Microsoft Azure, and Google Cloud Platform.
- Create a simple cloud infrastructure diagram.
- Improve my skills in Linux, Markdown, and GitHub.

## Cloud Infrastructure Components

The main components I learned about are compute, storage, networking, and the operating system.

Compute is used to run programs and applications. Storage is used to save files and data. Networking allows different devices and cloud resources to communicate with each other. The operating system manages the computer and allows users and programs to use its resources.
