# Mission 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

In this activity, I explored a Linux server using KillerCoda and checked the resources available in it. I also learned about the basic parts of cloud infrastructure and compared the services of AWS, Microsoft Azure, and Google Cloud.

## Objectives

- Check the resources of a Linux server.
- Understand the basic parts of cloud infrastructure.
- Compare AWS, Azure, and Google Cloud.
- Create a simple cloud infrastructure diagram.
- Practice writing technical information using Markdown.

## Cloud Infrastructure Components

The main components I learned about are compute, storage, networking, and the operating system.

Compute is used to process tasks and run applications. Storage keeps files and data. Networking allows different resources to communicate, while the operating system manages the server and its resources.

## Tools Used

- KillerCoda
- Ubuntu Linux
- GitHub
- Markdown
- LucidChart

## Linux Commands Executed

These are the commands I used while checking the server:
