# Cloud Infrastructure Components

## 1. Compute Resources

### Purpose

Compute resources provide the processing power needed to run programs, applications, and services. The CPU is one of the main compute resources of a server.

### Importance in Cloud Computing

Compute resources are important because applications need processing power to work. Cloud providers allow users to choose the amount of computing power they need without having to buy a physical computer.

### KillerCoda Example

In KillerCoda, the Linux server has a CPU that provides the processing power for the commands and programs that I run. I checked the CPU model and number of CPU cores using Linux commands.

---

## 2. Storage Resources

### Purpose

Storage is used to save files, programs, and other data. It allows information to remain available even after a program is closed.

### Importance in Cloud Computing

Storage is important because cloud applications need a place to save their data. Cloud storage also makes it easier to keep and access files without using the storage of a personal computer.

### KillerCoda Example

The KillerCoda server has disk storage where the Linux operating system, files, and programs are stored. I checked the disk information using the `df -h` command.

---

## 3. Networking Resources

### Purpose

Networking allows computers and cloud resources to communicate with each other. It also allows a server to communicate with users and other services.

### Importance in Cloud Computing

Networking is important because cloud services need a connection to communicate and provide services to users. Without a working network, users would not be able to properly access many cloud applications.

### KillerCoda Example

The KillerCoda environment has network information such as a hostname and IP address. I used Linux commands to check these details.

---

## 4. Operating System

### Purpose

The operating system manages the computer's hardware and software. It also provides an environment where users can run commands and applications.

### Importance in Cloud Computing

The operating system is important because cloud servers need an operating system to manage their resources and run applications. Linux is commonly used for servers because it is flexible and works well with many cloud technologies.

### KillerCoda Example

The KillerCoda environment provides a Linux operating system that I used to run commands, check server information, and manage files.

---

## Summary

Compute, storage, networking, and the operating system all work together in a cloud environment. The CPU handles processing, storage keeps data, networking allows communication, and the operating system manages the server. The KillerCoda environment helped me see these components in an actual Linux server.
