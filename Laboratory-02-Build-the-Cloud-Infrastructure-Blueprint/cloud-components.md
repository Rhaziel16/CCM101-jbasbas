# Cloud Components

## Compute Resources

### Purpose

Compute resources are responsible for doing the actual processing. They allow programs and applications to run on the server.

### Importance in Cloud Computing

Compute is important because a cloud service needs processing power to handle different tasks. The amount of compute can also be adjusted depending on what the application needs.

### KillerCoda Environment

In KillerCoda, the CPU is the main compute resource of the Linux server. I checked the CPU model and the number of CPU cores using Linux commands.

---

## Storage Resources

### Purpose

Storage is where files, programs, and other information are kept.

### Importance in Cloud Computing

Cloud applications need storage so they have a place for their data. It is also useful when a system needs to keep a large amount of information.

### KillerCoda Environment

The Linux server in KillerCoda has disk storage for its operating system and files. I checked the available disk space using the `df -h` command.

---

## Networking Resources

### Purpose

Networking lets the server communicate with other devices and services.

### Importance in Cloud Computing

A cloud system needs networking so users can connect to applications and different cloud resources can communicate with each other.

### KillerCoda Environment

I checked the network information of the KillerCoda server by getting its hostname and IP address using Linux commands.

---

## Operating System

### Purpose

The operating system manages the hardware and provides a place where programs and commands can run.

### Importance in Cloud Computing

A cloud server needs an operating system to manage its resources and run applications. Linux is commonly used in server environments.

### KillerCoda Environment

The KillerCoda server is running Ubuntu 24.04.4 LTS. I used the Linux terminal to check system information and perform different commands.

---

## Summary

These four components work together to make a server useful. Compute handles the processing, storage keeps the data, networking handles communication, and the operating system manages the whole environment.
