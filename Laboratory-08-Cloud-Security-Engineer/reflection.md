# Mission Reflection

Completing this activity helped me understand the importance of protecting a server. A host-based firewall adds another layer of security because it controls the traffic entering the server. Even if the main network security is breached, the firewall can still block connections that are not allowed.

Managing open network ports is important because unnecessary ports can give attackers more ways to access a server. Only the ports needed by the application and administrators should be allowed. In this activity, I learned how to allow SSH and port 8080 while blocking other incoming traffic by default.

In a real company, leaving MySQL port 3306 open to the public internet can be dangerous. Attackers may try to guess passwords, exploit database weaknesses, or access private information. A database should only be accessible to authorized users and applications. Proper firewall rules and strong passwords help protect important data.

This mission changed my perspective because I learned that starting a server is not enough to keep it safe. Even a simple web application needs proper security settings. I also learned that testing and checking firewall rules are important to make sure the configuration is correct.

My GitHub portfolio now contains eight laboratory missions, showing my progress in cloud computing. Organizing the activities into separate folders makes my work easier to understand and review. This activity also gave me practice in using Linux commands, configuring a firewall, taking screenshots, and documenting my work. Overall, I learned that server security requires careful configuration and regular checking.
