# Mission Reflection

A host-based firewall is important because it protects a server by controlling the network traffic entering and leaving the computer. Even if someone breaks through the physical network security, the firewall can still block unauthorized connections to the server. It adds another layer of protection and helps prevent attackers from accessing services they should not use.

Managing open network ports is also important because every open port can be a possible entry point for attackers. Some ports are needed for services to work, but unnecessary open ports can increase the risk of unauthorized access. Closing unused ports helps reduce the server's attack surface and makes it harder for attackers to find ways into the system. Regularly checking open ports also helps administrators identify services that should not be running.

In a real enterprise environment, leaving a database port like 3306 for MySQL open to the public internet is dangerous because anyone on the internet may try to connect to it. Attackers could attempt to guess passwords, exploit security weaknesses, or access sensitive company and customer information. If they successfully enter the database, they might steal, change, or delete important data. This could cause financial losses and damage the company's reputation. To prevent these risks, database access should be limited to trusted servers or authorized IP addresses. Strong passwords, proper user permissions, firewalls, and regular security updates should also be used.

From this activity, I learned that server security is not only about protecting the network but also about controlling access to the server itself. A host-based firewall and proper port management can help prevent unwanted connections. These simple security practices are important because they reduce risks and help keep company data safe. I also learned that administrators should regularly review their firewall rules and open ports instead of assuming that the server is already secure.
